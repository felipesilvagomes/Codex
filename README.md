# Codex

Protótipo visual de um aplicativo desenvolvido como parte do Trabalho de Conclusão de Curso (TCC).

## Sobre o projeto

O Codex é um projeto acadêmico desenvolvido com o objetivo de construir a interface visual do aplicativo que futuramente meu grupo irá desenvolver. Atualmente, encontra-se em fase de prototipagem, com foco na estruturação das telas e na experiência do usuário.

## Tecnologias utilizadas

- React Native
- Expo
- JavaScript

## Status do projeto

Em desenvolvimento — protótipo visual.
